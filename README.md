One image summing up the world news of Wednesday, 25 November 2026: the CIA
and ODNI cyberattack, Huawei's guilty verdict, the Houthi strike on Riyadh's
tallest tower, Ukraine sinking a Russian warship off Libya, Senegal's AFCON
title restored, and the WHO Ebola team evacuated in Congo.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`. The program is
deterministic: it writes the same bytes on every run, with no network.

## Entry
